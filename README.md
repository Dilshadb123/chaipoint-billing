Chai Point Billing

Project Description

Chai Point Billing is a Python-based project designed to manage the billing process for a chai shop. The project aims to make basic billing operations easier and more organized.

This project is being developed as part of practical software engineering training.

Features

- Python-based application.
- Chai shop billing management.
- Organized project structure.
- Simple and beginner-friendly implementation.

How to Run

1. Install Python 3.10 or above.
2. Download or clone the project repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Run the following command:

python main.py

6. Follow the instructions displayed by the application.
